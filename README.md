# صيّاد العروض — متتبع عروض أمازون مصر (مستعمل / علبة مفتوحة)

نظام مجاني بيشتغل لوحده 24/7:

- كل 30 دقيقة بيفحص قسم **المستعمل** على **amazon.eg فقط** (عروض Amazon Resale: مستعمل + Open Box).
- بيفلتر: **السعر أقل من 1000 ج.م** و **الخصم 70% أو أكثر**.
- بيبعتلك **رسالة واتساب** لكل عرض جديد (اسم المنتج، السعر، نسبة الخصم، رابط الشراء) — ومفيش عرض بيتبعت مرتين.
- بيعرض العروض المتاحة في **لوحة خاصة بكلمة سر** على Vercel.

## محتويات المشروع

| الملف | وظيفته |
|---|---|
| `scraper/tracker.py` | البرنامج الرئيسي: مسح، فلترة، منع تكرار، إشعارات |
| `scraper/amazon.py` | قراءة صفحات أمازون مصر |
| `scraper/notify.py` | إرسال الواتساب عن طريق CallMeBot |
| `scraper/config.json` | الإعدادات (السعر، الخصم، …) — الملف الوحيد اللي ممكن تحتاج تعدّله |
| `.github/workflows/tracker.yml` | التشغيل التلقائي كل 30 دقيقة على GitHub Actions |
| `data/state.json` | الذاكرة: إيه اللي اتبعت قبل كده + مكان التوقف في المسح |
| `web/` | لوحة العرض (تترفع على Vercel) |
| `web/data/deals.json` | العروض الحالية — بيتحدّث تلقائياً |
| `run_local.bat` | تجربة على جهازك (اختياري) |

## خطوات التشغيل (حوالي 15 دقيقة، من غير كتابة أي كود)

### 1) فعّل واتساب CallMeBot

1. افتح الصفحة الرسمية: <https://www.callmebot.com/blog/free-api-whatsapp-messages/>
2. ضيف رقم CallMeBot المكتوب في الصفحة لجهات الاتصال عندك.
3. ابعتله على واتساب الرسالة دي بالظبط: `I allow callmebot to send me messages`
4. هيرد عليك برسالة فيها **API key** — احتفظ بيه (هتحتاجه في الخطوة 3).

> ملحوظة: CallMeBot خدمة طرف ثالث مجانية — رقمك ونص الإشعارات بيمرّوا من عندها.

### 2) ارفع المشروع على GitHub

1. اعمل حساب على <https://github.com> لو مش عندك.
2. اضغط **New repository** → اكتب اسم (مثلاً `amazon-eg-deals`) → اختار **Public** → **Create repository**.
   - **ليه Public؟** GitHub Actions مجاني بلا حدود للمستودعات العامة فقط. المستودع الخاص له 2000 دقيقة/شهر والنظام ده بيحتاج أكتر، فهيقف بعد حوالي أسبوع.
   - اللي هيبقى ظاهر: الكود وقائمة العروض. اللي **مش** هيظهر: رقمك، مفتاح الواتساب، كلمة سر اللوحة (دول في Secrets).
3. في صفحة المستودع اضغط **uploading an existing file**.
4. افتح مجلد `amazon-eg-deals` على جهازك، حدّد **كل اللي جواه** (Ctrl+A) واسحبه لصفحة الرفع، وبعدين **Commit changes**.
5. اتأكد إن مجلد `.github` اترفع (هتلاقيه في قائمة الملفات). لو مش موجود:
   **Add file → Create new file** → في خانة الاسم اكتب `.github/workflows/tracker.yml` → افتح الملف من جهازك بالـ Notepad وانسخ محتواه والصقه → **Commit changes**.

### 3) ضيف بيانات الواتساب كـ Secrets

في المستودع: **Settings → Secrets and variables → Actions → New repository secret** وضيف اتنين:

| Name | Secret |
|---|---|
| `WHATSAPP_PHONE` | رقمك بكود الدولة، مثال: `+2010XXXXXXXX` |
| `CALLMEBOT_APIKEY` | المفتاح اللي وصلك من CallMeBot |

### 4) شغّل أول مرة واتأكد

1. افتح تبويب **Actions** (لو ظهر زر أخضر لتفعيل الـ workflows اضغطه).
2. اختار **Amazon EG Deal Tracker** → **Run workflow** → علّم على **Send a WhatsApp test message only** → **Run workflow**.
   لو وصلتك رسالة «تم ربط واتساب بنجاح» يبقى الواتساب تمام.
3. اضغط **Run workflow** تاني **من غير** علامة الاختبار. استنى 3–5 دقايق لحد ما تبقى العلامة خضراء.
4. افتح التشغيل واقرأ آخر سطر في خطوة **Run tracker**:
   - `status=ok` ← كله شغال، والعروض هتبدأ توصلك على واتساب.
   - `status=blocked` ← أمازون رفض الطلبات من سيرفرات GitHub. شوف «حل المشاكل» تحت.

بعد كده النظام هيشتغل لوحده كل 30 دقيقة.

### 5) انشر اللوحة الخاصة على Vercel

1. ادخل <https://vercel.com> واعمل حساب بـ **Continue with GitHub**.
2. **Add New… → Project** → اختار مستودع `amazon-eg-deals` → **Import**.
3. قبل ما تضغط Deploy:
   - **Framework Preset:** `Other`
   - **Root Directory:** اضغط Edit واختار `web`
   - **Environment Variables** — ضيف اتنين:

     | Key | Value |
     |---|---|
     | `DASHBOARD_USER` | اسم مستخدم تختاره |
     | `DASHBOARD_PASSWORD` | كلمة سر قوية تختارها |
4. اضغط **Deploy**. هتاخد رابط زي `https://amazon-eg-deals-xxxx.vercel.app`.
5. **اختبار الخصوصية (مهم):** افتح الرابط في نافذة متصفح خفي (Incognito). لازم يطلب اسم المستخدم وكلمة السر قبل ما يعرض أي حاجة. لو فتح من غير ما يسأل، ما تعتمدش على اللوحة وبلّغني.

كل ما GitHub يحدّث العروض، Vercel بيعيد نشر اللوحة تلقائياً خلال ثواني. واللوحة نفسها بتحدّث بياناتها كل 5 دقايق وهي مفتوحة.

## تعديل الإعدادات

افتح `scraper/config.json` على GitHub → أيقونة القلم ✏️ → عدّل → **Commit changes**.

| الإعداد | المعنى | القيمة الحالية |
|---|---|---|
| `max_price` | أقصى سعر (ج.م) — العرض لازم يكون أقل منه | 1000 |
| `min_price` | أقل سعر — ارفعه (مثلاً 100) لو مش عايز إشعارات عن إكسسوارات بـ 20 جنيه | 0 |
| `min_discount` | أقل نسبة خصم | 70 |
| `discount_basis` | الخصم محسوب من إيه: `new` = أرخص سعر جديد لنفس المنتج، `list` = السعر الأصلي المشطوب، `highest` = الأعلى فيهم | highest |
| `pages_per_run` | عدد صفحات البحث في كل تشغيل | 20 |
| `max_whatsapp_per_run` | أقصى عدد رسائل في التشغيل الواحد (الباقي بيتبعت في التشغيل اللي بعده) | 8 |
| `renotify_price_drop_percent` | لو سعر عرض اتبعت قبل كده نزل بالنسبة دي، يتبعت تاني | 10 |
| `forget_after_days` | بعد كام يوم من اختفاء العرض ممكن يتبعت تاني لو رجع | 30 |

## إزاي بيشتغل (باختصار)

1. كتالوج المستعمل تحت 1000 ج.م على أمازون مصر حوالي 3000+ منتج، وأمازون بيعرض 7 صفحات بس لكل بحث. فالبرنامج مقسّم الأسعار لـ 15 شريحة وبيلف عليهم بالدور: كل تشغيل بيكمّل من مكان ما وقف، والدورة الكاملة بتاخد تقريباً ساعتين.
2. أي منتج شكله مطابق بيتفتحله صفحة «كل العروض» للتأكد من السعر والحالة الفعلية (Used / Open Box) والبائع.
3. العروض الموجودة على اللوحة بيتعاد فحصها كل تشغيل، واللي اتباع أو سعره اتغيّر بيتشال.
4. كل عرض بيتبعت على واتساب مرة واحدة بس (محفوظ في `data/state.json`).

## حل المشاكل

- **`status=blocked` في GitHub Actions:** أمازون أحياناً بيرفض سيرفرات GitHub. البرنامج مش بيحاول يتحايل على فحص الروبوت — بيقف ويحاول في الميعاد اللي بعده، ولو فضل مرفوض 3 ساعات بيبعتلك تنبيه واتساب. لو الرفض دايم، الحل البديل هو تشغيل البرنامج من جهازك (السحب من جهازك اتجرّب وشغال).
- **التشغيل مش كل 30 دقيقة بالظبط:** GitHub بيأخّر المهام المجدولة أحياناً 5–20 دقيقة وقت الزحمة. ده طبيعي.
- **الواتساب مش بيوصل:** راجع الـ Secrets (الرقم بكود الدولة `+20`)، وجرّب تشغيل الاختبار من الخطوة 4. لو CallMeBot وقّف حسابك ابعتله رسالة التفعيل تاني.
- **اللوحة مش بتتحدّث:** في Vercel افتح المشروع → Deployments واتأكد إن فيه deployment جديد بعد كل تحديث. لو مفيش: Settings → Git واتأكد إن المستودع مربوط.
- **اللوحة بتقول «Dashboard is locked»:** `DASHBOARD_PASSWORD` مش متضاف في Vercel. ضيفه واعمل Redeploy.
- **GitHub وقّف الـ workflow:** لو المستودع فضل 60 يوم من غير أي نشاط GitHub بيوقف الجدولة. البرنامج بيعمل commit كل تشغيل فده مش المفروض يحصل، ولو حصل اضغط **Enable workflow** في تبويب Actions.

## ملاحظات لازم تعرفها

- **شروط أمازون:** شروط استخدام أمازون بتمنع السحب الآلي. البرنامج ده للاستخدام الشخصي وبمعدل هادي (طلب كل 2–3 ثواني، حوالي 85 طلب كحد أقصى كل نص ساعة)، لكن أمازون ممكن يحظر الطلبات في أي وقت.
- **نسبة الخصم:** محسوبة من سعر المنتج الجديد المعروض على أمازون. بعض البائعين بيحطّوا سعر جديد مبالغ فيه، فالخصم ممكن يبان أكبر من الحقيقي — راجع المنتج قبل الشراء.
- **الفورية:** أقصى تأخير بين ظهور العرض والإشعار هو مدة الدورة الكاملة (حوالي ساعتين)، مش 30 دقيقة، لأن كل تشغيل بيغطي جزء من الكتالوج.
- **أول يوم:** هيوصلك عدد كبير من الرسائل (8 كل نص ساعة) لحد ما العروض الموجودة حالياً تخلص، وبعدها هيوصلك الجديد بس.

## تجربة على جهازك (اختياري)

دبل كليك على `run_local.bat` — بيفحص مرة واحدة ويحدّث `web/data/deals.json` من غير ما يبعت واتساب.
